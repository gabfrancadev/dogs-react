# 🐶 Dogs

Dogs is a social network for dog lovers developed with React.

The project allows users to interact with dog photos, explore posts, and navigate through a social network-style interface.

This project was developed during my React studies, with a focus on component-based development, routing, state management, forms, and API integration.

## 🚀 Features

* User authentication
* User registration
* Dog photo feed
* Photo posting
* Comments
* User profiles
* Likes
* Responsive interface
* API integration

## 🛠️ Technologies

* React
* JavaScript
* Vite
* React Router
* CSS
* REST API

## 📚 What I Practiced

* React components and props
* State management
* React hooks
* Client-side routing
* Form handling and validation
* API requests
* Authentication
* Reusable components
* Responsive design

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/gabfrancadev/dogs-react.git
```

Navigate to the project directory:

```bash
cd dogs-react
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 📦 Production Build

To create a production build:

```bash
npm run build
```
